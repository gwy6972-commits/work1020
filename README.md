# 국방예산 신규사업 분석 대시보드 웹 애플리케이션

2027년 국방예산 정부안 및 신규사업 엑셀(.xlsx, .xls) / CSV 파일을 입력받아 **분야별**, **주관기관별**, **신규사업별**로 분석 및 시각화하는 통합 대시보드 웹 페이지입니다.

---

## 🚀 빠른 시작 (실행 방법)

### 방법 1. 브라우저로 바로 열기 (가장 간편한 방법)
`c:\work1020\web\index.html` 파일을 더블 클릭하여 크롬(Chrome) 또는 엣지(Edge) 브라우저에서 바로 열 수 있습니다.
- 모든 라이브러리(`xlsx.full.min.js`, `chart.umd.min.js`)가 로컬 폴더(`lib/`)에 포함되어 있어 **인터넷 연결 없이도 100% 오프라인 작동**합니다.

### 방법 2. 로컬 웹 서버로 실행
PowerShell 터미널에서 다음 명령어를 실행합니다:
```powershell
cd c:\work1020\web
.\start_server.ps1
```
- 기본 브라우저에서 `http://localhost:8080/`이 자동으로 열립니다.

> **스마트 컬럼 인식 기능**:
> - 컬럼 이름이 완전히 일치하지 않아도(`사업명`, `과제명`, `담당부서`, `예산`, `증감액` 등 유사어) 정규식으로 자동 매핑됩니다.
> - 시트가 2개인 경우(시트1: 현황, 시트2: 세부 추진내용·수혜대상·법령·기대효과), 자동으로 연번 또는 사업명을 기준으로 결합(Join)되어 상세 모달에서 표시됩니다.
> - 파일 내 `분야` 컬럼이 없더라도 주관기관 및 사업명 키워드(R&D, 간부처우, 예비군, AI행정 등)를 바탕으로 분야를 지능형 자동 분류합니다.

## ✨ 주요 기능 및 대시보드 화면 안내

1. **상단 핵심 KPI 요약 카드 (5종)**
   - 총 신규 사업 수, 총 신규 예산액, 최대 규모 신규사업, 참여 주관기관 및 부서 수, 사업당 평균 예산액 실시간 집계

2. **종합 대시보드 (Overview)**
   - **분야별 예산 도넛 차트**: 분야별 예산 점유율 시각화 (도넛 클릭 시 해당 분야 필터링)
   - **신규사업 예산 Top 8 수평 바 차트**: 사업별 예산 규모 순위 (바 클릭 시 사업 상세 팝업)
   - **핵심 시사점 요약 카드**: 2027 국방 신규사업의 3대 핵심축 요약

3. **분야별 심층 분석 (Categories)**
   - 사업 분야별 / 주관 기관별 기준 전환 토글
   - 예산 규모(막대) 및 사업 건수(선) 복합 차트
   - 분야별 세부 사업 카드 및 평균 사업비 분석

4. **신규사업별 상세 목록 및 필터링 (Projects)**
   - 실시간 텍스트 검색 (사업명, 주관부서, 내용, 담당자)
   - 분야별 / 기관별 / 예산 규모별 (500억 이상, 100~500억 등) 드롭다운 필터
   - 테이블 뷰 vs 카드 뷰 전환
   - 다중 정렬 (예산순, 증감액순, 연번순, 가나다순)

5. **사업 상세 모달 (Detail Modal)**
   - 각 사업 클릭 시 팝업: '26년 예산, '27년 정부안, 증감액, 핵심 추진목표, 지원대상, 법령근거, 추진일정, 기대효과 일목요연 표시

6. **사업 비교분석 (Compare)**
   - 목록에서 체크박스 선택 시 2~4개 사업을 나란히 배치하여 예산 및 추진내용 비교

7. **데이터 내보내기 & 기타 편의기능**
   - 현재 필터링된 데이터를 새 엑셀(.xlsx) 또는 CSV로 즉시 내보내기
   - 인쇄 최적화 (`@media print` 지원)
   - 다크 모드 / 라이트 모드 전환 지원
